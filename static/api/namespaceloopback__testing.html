◆ plot_matched()

loopback_testing.plot_matched (   matched,
  sample_rate,
  tx = None,
  velocity_factor = 2/3,
  loopback = True,
  coax_length = None,
  zero_sample_idx = 159 
)

Plot matched filter output with physical distance scaling.

Args: matched: 2D array (samples x pulses) after matched filtering. sample_rate: sampling rate in Hz. tx: optional transmit chirp (1D array). If provided, its length is used to compute the delay offset. If not, a fallback is used. velocity_factor: fraction of light speed inside the medium (coax), default 2/3 for typical coax. loopback: True if the signal traverses the medium one-way (tx->rx). For free-space reflections set False (two-way and divide by 2). coax_length: optional expected coax length in meters; if provided, a vertical line and annotation for expected return is drawn.
